<h1 align="center">Academic Door / 学术传送门</h1>

<p align="center">
  面向中文读者的开放学术信息服务。<br>
  读好文献，用好论文。
</p>

Academic Door 致力于建设可靠、可检索、可复用的经济学学术公共品，将公开论文数据、中文整理、学术浏览与多平台内容生产连接起来。

## 公开项目

| 项目 | 内容 | 状态 |
|---|---|---|
| [Academic Door 主页](https://academic-door.github.io/) | 品牌入口与项目导航 | 持续建设 |
| [NBER Working Papers CN](https://academic-door.github.io/nber-working-papers-cn/) | NBER 周报、月报、中英文摘要、归档与检索 | 运行中 |
| [Econ Papers Daily](https://academic-door.github.io/econ-paper-monitor/) | 每日经济学论文与工作论文监测 | 运行中 |
| [Academic Door Journals](https://github.com/academic-door/journals) | TOP5、Field Journals、统一期刊数据引擎与 Composer | 启动建设 |

## 建设原则

- **来源透明：** 保留论文官网、DOI、抓取时间和字段来源。
- **完整优先：** 对卷期论文数量、顺序、作者、摘要和重复项进行检查。
- **中文友好：** 提供便于中文读者检索和浏览的标题、摘要与专题整理。
- **开放复用：** 同一份结构化数据服务网站、RSS、公众号和其他平台。
- **人工负责：** AI 辅助采集、翻译与整理，最终研究判断和正式引用以原文为准。
- **隐私安全：** 公开仓库不保存 API 密钥、私有稿件、邮箱凭据或本机数据。

## 开发与协作

Academic Door 使用 Issue、独立分支、Pull Request、自动测试和人工 Review 管理变更。通用协作规范见 [Agent Workflow Template](https://github.com/academic-door/agent-workflow-template)。

## 说明

Academic Door 是独立、非官方、非营利的学术交流项目。论文内容、版本、引用与版权信息请以原始期刊、研究机构和论文原文为准。中文内容由 AI 辅助翻译与人工整理，仍可能存在疏漏。
